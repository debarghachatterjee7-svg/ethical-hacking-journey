# Linux Enumeration Toolkit — Updated Project Documentation

## 1. `enumtool.sh`

### Title
**Administrative Dashboard System — Linux Enumeration Toolkit**

### Description
`enumtool.sh` is the main Bash executable of the Linux Enumeration Toolkit. It implements the interactive Administrative Dashboard and connects the project's Linux enumeration, diagnostics, security-audit, service, important-file, and reporting functions through a structured menu.

The script currently provides access to:

- System Information
- OS & Kernel Overview
- Users & Groups
- Process Diagnostics
- Network Status
- Storage Information
- Security & Permissions Audit
- Active Services
- Important Files Check
- Full Report Generation
- Clean Dashboard Exit

The script demonstrates practical Bash concepts including functions, variables, `while` loops, `case` statements, `if` conditions, user input with `read`, command substitution, command detection, file tests, output/error redirection, and structured terminal output.

### Project Role
`enumtool.sh` is the **core application file** of the project. The other documentation, screenshots, notes, labs, and generated reports describe or provide evidence for the functionality implemented in this script.

## Project Overview

The **Administrative Dashboard System** is a Bash-based Linux enumeration and diagnostics toolkit developed as a practical cybersecurity and Linux-learning project.

The project takes individual Linux commands and combines them into an interactive dashboard. Instead of manually executing every command separately, the user can select a module from the dashboard and receive organized information about the local Linux environment.

The project has progressed from basic Bash practice into a multi-module diagnostic application containing system, operating-system, user, process, network, storage, security, service, file-audit, and reporting functionality.

The project is being developed incrementally so that every major feature is understood, implemented, tested, documented, and connected to the main dashboard.

# MD5 / Checksum Learning

MD5 checksum concepts were also studied during the learning process.

Examples:

```bash
md5sum filename
```

and:

```bash
echo -n "hello" | md5sum
```

Important lessons:

- A small input change changes the checksum.
- `echo -n` prevents a newline from becoming part of the input.
- MD5 is useful for learning checksum and integrity concepts.
- MD5 should not be treated as a modern secure cryptographic hash for security-sensitive applications.
- SHA-256 is a stronger modern choice for integrity use cases.

Python-based hashing will be learned later rather than being forced into the current Bash project.
