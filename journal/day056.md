**Answer:**

Understanding the method is more important because the same concepts can be applied to completely new problems.

### Q3. What should you do when a command produces unexpected output?

**Answer:**  
Inspect the output, check the command syntax and assumptions, read any error message, and adjust the approach based on the evidence.
