## 3. What Is a Network?

A network allows devices to communicate and exchange information.

A simplified model is:

```text
Device A
   ↓
Network
   ↓
Device B
```

Examples of networked devices include:

```text
Computer
Phone
Server
Router
Printer
IoT device
```

The important idea is:

> **Networking is about communication between systems.**

---

## 4. Hosts, Clients and Servers

A **host** is a device connected to a network.

A **client** requests a service, while a **server** provides a service.

Mental model:

```text
Client
   ↓ request
Server
   ↓ response
Client
```

This client-server model appears repeatedly in web applications and cybersecurity.

---

## 5. IP Address Revision

An IP address provides logical network addressing.

IPv4 addresses are commonly written like:

```text
192.168.1.10
```

An important distinction is:

```text
IP address → logical network addressing
MAC address → link-layer/interface addressing
```

They serve different purposes.

---

## 6. Private and Public IP Concepts

### Private IP

Private addressing is used within private networks.

Common private IPv4 ranges include:

```text
10.0.0.0/8

192.168.0.0/16
```

### Public IP

Public IP addressing is used for communication across public networks such as the Internet.

Mental model:

```text
Private network
      ↓
Router
      ↓
Public Internet
```

## 10. TCP Revision

TCP is a connection-oriented transport protocol.

Important characteristics:

- Connection-oriented
- Reliable delivery
- Ordered data delivery
- Retransmission mechanisms

Mental model:

```text
Connection
   ↓
Data
   ↓
Reliable delivery
```

TCP is useful where reliable ordered delivery is important.

---

## 11. UDP Revision

UDP is a connectionless transport protocol.

Compared with TCP, it has lower protocol overhead and does not provide TCP's built-in reliable ordered delivery.

Mental model:

```text
Send datagram
     ↓
No TCP-style connection
```

UDP can be useful when low overhead and timeliness are important.

---

## 12. TCP vs UDP

| Feature | TCP | UDP |
|---|---|---|
| Connection-oriented | Yes | No |
| Built-in reliable delivery | Yes | No |
| Ordered delivery | Yes | No |
| Protocol overhead | Higher | Lower |
| Examples | Web, SSH, reliable transfers | DNS queries, real-time/low-overhead traffic |

Memory shortcut:

```text
TCP → reliability
UDP → low overhead
```

The two models provide different ways of organizing networking functions.

## 23. Packets and Encapsulation

A simplified view of network communication is:

```text
Application data
      ↓
Transport information
      ↓
Network information
      ↓
Link information
      ↓
Transmission
```

This process is called **encapsulation**.

At the receiving side, the layers process the information in the reverse direction.

Mental model:

```text
Data
 ↓
Segment/Datagram
 ↓
Packet
 ↓
Frame
 ↓
Bits/signals
```

The exact terminology depends on the protocol and layer.

## 29. Professor Questions & Answers

### Q1. What is the purpose of an IP address?

**Answer:**  
It provides logical network addressing so systems or interfaces can be identified and reached at the network layer.

### Q2. What is the difference between an IP address and a MAC address?

**Answer:**  
An IP address is used for network-layer addressing, while a MAC address is associated with a network interface at the data-link layer.

### Q3. Why do we need ports?

**Answer:**  
Ports help identify particular network services or endpoints on a host.

### Q4. What is the difference between TCP and UDP?

**Answer:**  
TCP is connection-oriented and provides reliable ordered delivery, while UDP is connectionless and has lower protocol overhead without TCP's built-in reliability mechanisms.

### Q5. What does DNS do?

**Answer:**  
DNS translates domain names into IP addresses and provides other types of DNS records.

### Q6. What does DHCP do?

**Answer:**  
DHCP can automatically provide network configuration to clients.

### Q7. What is HTTPS?

**Answer:**  
HTTPS is HTTP protected by TLS.

### Q8. What is the purpose of TLS?

**Answer:**  
TLS provides security properties such as confidentiality, integrity and authentication for protected network communication.

### Q9. Why is the OSI model useful?

**Answer:**  
It provides a layered conceptual framework that helps organize and troubleshoot networking concepts.

### Q10. Why is networking important in cybersecurity?

**Answer:**  
Modern systems communicate over networks, so understanding addresses, protocols, ports, traffic and services is essential for understanding network and application security.
