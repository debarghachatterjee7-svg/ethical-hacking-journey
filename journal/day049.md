## 13. Professor Questions & Answers

### Q1. Why continue debugging after previous testing found no bugs?

**Answer:**  
One successful test does not prove that a program will behave correctly in every situation. Repeated testing increases confidence in stability.

### Q2. Why didn't you modify the code today?

**Answer:**  
No confirmed bug or requirement for a change was identified. Making unnecessary modifications could introduce new problems.

### Q3. What is the difference between testing and debugging?

**Answer:**  
Testing checks whether the program behaves as expected. Debugging is the investigation and correction process used when unexpected behaviour or an error is discovered.

### Q4. Does "no bugs found" mean the program has no bugs?

**Answer:**  
No. It means no bugs were observed during the tests that were performed.

### Q5. Why is documenting a no-bug day useful?

**Answer:**  
It creates a record of the testing performed and prevents the project history from implying that every day must contain a code change.
