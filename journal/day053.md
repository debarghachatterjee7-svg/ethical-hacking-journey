## 22. Professor Questions & Answers

### Q1. What is the difference between `grep` and `find`?

**Answer:** `grep` is mainly used to search or filter text, while `find` locates files and directories based on conditions.

### Q2. Why are pipelines important?

**Answer:** They allow the output of one command to become the input of another, allowing small utilities to form useful workflows.

### Q3. Why should `cat` not always be used on large files?

**Answer:** It can produce excessive terminal output. `grep`, `head`, or `tail` may be more appropriate.

### Q4. What does `2>/dev/null` mean?

**Answer:** It redirects standard error to `/dev/null`, preventing that error output from appearing in the terminal.

### Q5. Why are Linux permissions important for cybersecurity?

**Answer:** They control who can read, modify, or execute resources, making access control a fundamental security concept.

### Q6. Why revise Linux before deeper cybersecurity?

**Answer:** Many security tools and techniques interact directly with the operating system, so strong Linux fundamentals make later security concepts easier to understand.
