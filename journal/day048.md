## 13. Professor Questions & Answers

### Q1. Why debug a project that already appears to work?

**Answer:**  
Normal execution does not guarantee that every part of a program behaves correctly. Debugging provides a way to inspect execution and detect problems that may not be immediately visible.

### Q2. What happens when debugging finds nothing?

**Answer:**  
The result should still be documented honestly. No bug should be invented simply to create a code change.

### Q3. Should code always be changed after testing?

**Answer:**  
No. If testing shows that the current implementation behaves as expected, unnecessary changes can introduce new bugs.

### Q4. What was the result of today's debugging?

**Answer:**  
No bugs or additional errors were found within the scope of today's testing.

### Q5. Does this prove the project has zero bugs?

**Answer:**  
No. It only means that no bugs were observed during the tests performed today.
