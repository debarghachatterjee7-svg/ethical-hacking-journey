## 23. MD5 / Checksum Revision

MD5 was revised as part of maintaining earlier learning.

Commands reviewed:

```bash
md5sum filename
```

and:

```bash
echo -n "hello" | md5sum
```

A particularly important comparison was:

```bash
echo -n "hello" | md5sum
```

versus:

```bash
echo "hello" | md5sum
```

The results differ because the second command includes a newline in the input.

Important lessons:

```text
Input
 ↓
Hash function
 ↓
Digest
```

and:

```text
Small input change
 ↓
Different digest
```

MD5 remains useful for understanding checksum concepts, but it should not be considered a modern secure cryptographic hash for security-sensitive applications.

## 27. Security Finding Classification

The project now follows a more careful classification mindset.

### Observation

Something was discovered.

Example:

```text
SUID binary exists
```

### Finding

The observation is relevant enough to investigate.

### Vulnerability

There is sufficient evidence that a security weakness exists.
