## 14. Professor Questions & Answers

### Q1. Why perform a complete run after finishing the code?

**Answer:**

Because writing code and testing the complete application are different activities. A full run checks whether the components work together as expected.

### Q2. Why not keep adding features indefinitely?

**Answer:**

A project needs a defined completion point. Once the planned functionality is implemented and verified, it is better to document and finalize the project rather than adding unnecessary complexity.

### Q3. What is the purpose of final verification?

**Answer:**

Final verification provides confidence that the completed implementation behaves correctly within the tested scope.

### Q4. Does final verification prove that there can never be a bug?

**Answer:**

No. Testing can increase confidence but cannot mathematically prove that software contains no possible bugs.

**Answer:**
